Incorporar ventas de un corte

El efectivo se incorpora a Caja. La tarjeta se incorpora al Banco cuando se confirme el abono. Cada medio se registra por separado y una sola vez por corte.

No incorpores un corte si ya capturaste esas mismas ventas manualmente. Se incorpora el importe bruto: si el banco descontó una comisión, registra también ese egreso en Banco. No se incorpora el fondo inicial ni el efectivo contado.
